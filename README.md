A tiny, deterministic program for the make.fun competition
"One Word, One Username, One Reward". It writes my own make.fun
username, one word and nothing else, to `/output/entry.txt`:

> limit99

The program checks the gate's 1–30 character limit itself before
writing. No network, no randomness: every run produces the same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
